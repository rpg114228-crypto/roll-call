# 一中隊點名助手

手機優先的軍事點名管理工具，支援多時段差勤設定與標準回報產生。

**線上版本：** https://rpg114228-crypto.github.io/roll-call/

---

## 功能

- **多時段點名**：早點名、0740、1200、1330、1700、1850、晚點名、軍訓課、研習假、研習1700、研習1800
- **勾選模式**：點人名選差勤，點班名全班套用
- **文字輸入模式**：貼上班長回報自動解析套用
- **預填公差**：消委、餐勤固定人員一鍵預填
- **標準回報產生**：自動格式化點名回報，支援含班別版本
- **歷史記錄**：儲存最近 30 筆回報

---

## 差勤類型

| 類別 | 項目 |
|------|------|
| 假別 | 公假、事假、病假、喪假、補休、正常假 |
| 勤務 | 站哨、下夜、餐勤、班消、外派、罰勤、值星、差勤、燒委、巡水電 |
| 訓練 | 正課、龍隊、研習 |
| 委員 | 消委、修委、社團、校旗隊、美工、BMI |
| 其他 | 校隊、服檢、安檢、寢休、收委、榮團會、自行帶回 |
| 研習假 | 有意願（黃）、無意願（紅）、無資格（灰） |

---

## 研習假邏輯

| 身份 | 算應到 | 需點名 | 回報 |
|------|--------|--------|------|
| 無資格 | ✗ | ✗ | 不出現 |
| 有意願 | ✓ | ✓（離校前） | 在勤，不標注 |
| 無意願 | ✓ | ✓ | 特別標注 |

- **研習假**（二/四）：單一時段
- **研習1700/1800**（三）：兩批出發，1700已出發者在1800排除
- 應到 = 總人數 − 無資格人數
